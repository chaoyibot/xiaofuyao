## 🎯 项目定位

氟尿嘧啶口服乳品类 **首个专属售后服务小程序**，为患者、医师、经销商提供：
- 📦 **产品介绍** —— 看得懂、信得过
- 🎓 **学术培训** —— 权威、专业、高效
- 🛠️ **售后服务** —— 用药安心、服务贴心

## 🏗️ 技术栈

| 层级 | 技术 | 理由 |
|:---|:---|:---|
| 前端 | uni-app + Vue 3 | 一次开发，多端运行 |
| 后端 | 腾讯云开发 CloudBase | 免运维、弹性扩容 |
| 数据库 | MySQL + COS | 文档、图片云端托管 |
| 实时通讯 | 腾讯云 IM | 客服、消息推送 |
| AI 能力 | 混元大模型 | 智能客服、内容理解 |
| 部署 | 微信开发者工具 | 一键发布 |

## 🚀 快速开始

### 前端开发
```bash
cd frontend
npm install
# 微信小程序
npm run dev:mp-weixin
```

### 云函数开发
```bash
# 在微信开发者工具中打开 cloudfunctions 目录
# 右键 → 上传并部署
```

### 测试
```bash
npm run test          # 单元测试
npm run test:e2e      # E2E 测试
npm run test:load     # 压测
```
