# 🛡️ 小福药 · 合规规则引擎

> **目的**：自动化审查小程序所有文案的医疗合规性  
> **依据**：《药品管理法》《互联网药品信息服务管理办法》《医疗广告管理办法》

---

## 1. 绝对禁止词（出现任一即不通过）

| 类别 | 关键词 |
|:---|:---|
| 治愈承诺 | 治愈、根治、完全康复、彻底治好、100% 有效 |
| 误导宣传 | 最好、最强、第一、唯一、特效、祖传 |
| 夸大疗效 | 药到病除、立竿见影、一次见效 |
| 违规承诺 | 无毒副作用、零风险、安全无副作用 |

## 2. 必须出现的信息

- ✅ 完整药品通用名："氟尿嘧啶口服乳"
- ✅ "请在医生指导下使用"
- ✅ "请仔细阅读说明书"
- ✅ 不良反应提示
- ✅ 禁忌症提示
- ✅ "本品为处方药"

## 3. 风险提示模板

### 3.1 首页底部
```
⚠️ 药品提示：氟尿嘧啶口服乳为处方药，请凭医师处方购买、使用。
本品需在医生指导下使用，用药前请仔细阅读说明书。
```

### 3.2 用药相关页面
```
⚠️ 风险提示：
• 本品为化疗药物，可能引起骨髓抑制、消化道反应等
• 用药期间需定期复查血常规、肝肾功能
• 出现严重不良反应请立即就医
• 孕妇、哺乳期妇女禁用
```

### 3.3 学术内容页面
```
📚 学术内容仅供医务人员参考，不作为临床决策唯一依据
具体用药方案请遵医嘱
```

## 4. 合规检查清单

### 4.1 文案层面
- [ ] 无绝对禁止词
- [ ] 风险提示完整
- [ ] "请遵医嘱"明确出现
- [ ] "本品为处方药"明确出现
- [ ] 不良反应有提示
- [ ] 禁忌症有说明

### 4.2 页面层面
- [ ] 首页有底部风险提示
- [ ] 用药页面有详细风险说明
- [ ] 学术内容有"仅供医务人员参考"
- [ ] 不展示价格（如涉及销售）
- [ ] 联系方式清晰（如需处方咨询）

### 4.3 数据层面
- [ ] 不展示具体临床数据来源不明的疗效数字
- [ ] 引用研究需注明出处
- [ ] 不展示"X 例患者 X% 治愈"等违规数据

## 5. 审查自动化

详见 `scripts/合规审查.py` 脚本，可批量审查所有文案。
