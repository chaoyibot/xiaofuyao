## 1. 文件命名

### 1.1 页面文件
```
pages/模块名/功能名.vue
示例：
  pages/home/index.vue        ✅
  pages/product/detail.vue    ✅
  pages/product/Detail.vue    ❌（避免大写）
  pages/product/detail_page.vue ❌（避免冗余）
```

### 1.2 组件文件
```
components/组件名.vue
示例：
  components/AppHeader.vue        ✅
  components/MedicalAlert.vue     ✅
  components/medical-alert.vue    ❌（统一 PascalCase）
```

### 1.3 JS / TS 文件
```
kebab-case.js / kebab-case.ts
示例：
  utils/request.js     ✅
  utils/format-time.js ✅
  utils/Request.js     ❌
```

## 2. Vue 组件规范

### 2.1 使用 `<script setup>` 语法

```vue
<script setup>
import { ref, computed } from 'vue'
// 自动暴露给模板
</script>
```

### 2.2 Props 定义

```js
const props = defineProps({
  // ✅ 推荐：对象形式 + 类型 + 默认值 + 验证
  title: { type: String, required: true },
  count: { type: Number, default: 0 },
  status: { type: String, default: 'active', validator: v => ['active', 'inactive'].includes(v) }
})

// ❌ 避免：数组形式
defineProps(['title', 'count'])
```

### 2.3 Emits 定义

```js
const emit = defineEmits(['click', 'change', 'submit'])

// 使用
emit('click', { id: 1 })
```

### 2.4 响应式数据

```js
import { ref, reactive, computed, watch, onMounted } from 'vue'

const count = ref(0)
const user = reactive({ name: '', age: 0 })
const double = computed(() => count.value * 2)
```

## 3. 样式规范

### 3.1 使用 SCSS + scoped

```vue
<style lang="scss" scoped>
@import "@/uni.scss";

.my-class {
  color: $uni-color-primary;
  font-size: $uni-font-size-base;
}
</style>
```

### 3.2 避免内联样式

```vue
<!-- ❌ 避免 -->
<view style="color: #1565C0; padding: 24rpx">...</view>

<!-- ✅ 推荐 -->
<view class="my-class">...</view>
```

### 3.3 主题色用变量

```scss
/* ❌ 避免硬编码 */
.btn { background: #1565C0; }

/* ✅ 用变量 */
.btn { background: $uni-color-primary-light; }
```

### 3.4 单位用 rpx

```scss
/* ✅ 推荐 rpx（小程序自适应） */
.card { padding: 24rpx; font-size: 28rpx; }

/* ❌ 避免 px（不会自适应） */
.card { padding: 12px; font-size: 14px; }
```

## 5. 注释规范

### 5.1 组件顶部注释

```vue
<script setup>
/**
 * ProductCard - 药品卡片
 * @description 展示药品基本信息，支持点击进入详情
 * @props {Object} product - 药品数据
 * @emits click - 点击卡片
 */
</script>
```

### 5.2 函数注释

```js
/**
 * 计算 BSA（体表面积）
 * @param {number} height - 身高（cm）
 * @param {number} weight - 体重（kg）
 * @returns {number} BSA（m²）
 */
function calculateBSA(height, weight) {
  return Math.sqrt((height * weight) / 3600)
}
```

### 5.3 关键逻辑注释

```js
// ✅ 重要逻辑必须注释
// 严重不良反应（3-4 级）需立即触发告警
if (severity >= 3) {
  await sendUrgentAlert()
}
```

## 6. Git 提交规范

### 6.1 Commit Message 格式

```
<emoji> <type>(<scope>): <subject>

<body>

<footer>
```

### 6.2 Type 类型

| Type | 用途 | Emoji |
|:---|:---|:---:|
| `feat` | 新功能 | ✨ |
| `fix` | 修复 | 🐛 |
| `docs` | 文档 | 📝 |
| `style` | 样式 | 💄 |
| `refactor` | 重构 | ♻️ |
| `test` | 测试 | ✅ |
| `chore` | 构建/工具 | 🔧 |
| `perf` | 性能 | ⚡ |

### 6.3 示例

```bash
✨ feat(product): add product detail page
🐛 fix(service): fix medication checkin bug
📝 docs(api): update API spec v1.1
💄 style(home): adjust color to style A
```

## 8. 安全规范

### 8.1 数据脱敏

```js
// ✅ 脱敏展示
function maskPhone(phone) {
  return phone.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2')
}
```

### 8.2 禁止硬编码敏感信息

```js
// ❌ 禁止
const apiKey = 'sk-xxxxx'

// ✅ 用环境变量
const apiKey = import.meta.env.VITE_API_KEY
```

### 8.3 用户输入验证

```js
// ✅ 验证用户输入
function validatePhone(phone) {
  return /^1[3-9]\d{9}$/.test(phone)
}
```
